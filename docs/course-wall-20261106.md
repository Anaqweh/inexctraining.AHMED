# حائط الأعمال (لوحات مستقلة) — 2026-11-06

**ما هو:** خدمة مستقلة في الموقع (`/wall/`): أي شخص ينشئ لوحة باسم دورته وبريده، فيصله **رابط الإدارة** على بريده ويصبح مدير اللوحة (كل الإعدادات بيده). المتدربون يفتحون رابط المشاركة `/wall/?b=CODE`، يكتبون أسماءهم فقط، يرفعون أعمالهم، ويعلّقون ويتفاعلون، مع زر خروج.

**العرض الجذري لأي ملف:** كل ملف مرفوع يُحوَّل على الخادم (`inexc-api/wall-render.py`) إلى صور صفحات PNG: الصور مباشرة، PDF عبر poppler، Word/PowerPoint/Excel/نصوص عبر LibreOffice ثم poppler. كل صفحة تُختم بشريط «توقيع التميز» (اسم المتدرب + شركة التميز الابتكاري + INEXC TRAINING + رقم الصفحة) بخط أميري. الفيديو والصوت يُشغَّلان من الملف الأصلي؛ الأنواع الأخرى تُنزَّل.

**الـAPI** (`inexc-api/course-wall.js`): جداول إضافية `wall_boards / wall_members / wall_items / wall_comments / wall_reactions`. المفاتيح تُخزَّن مجزأة (sha256). الرؤوس: `X-Wall-Key` للمدير، `X-Wall-Member` للمتدرب. الملفات تحت `/app/uploads/trainee-private/wall/<item>/` ولا تُخدَم إلا عبر مسارات `/api/wall/...`. طابور تحويل بتزامن 2 ويُستأنف عند إقلاع الخادم.

**الإعدادات (مفاتيح تشغيل/إيقاف):** الرفع مفتوح، التعليقات، التفاعل، موافقة قبل الظهور، الختم، السماح بالتنزيل، إغلاق اللوحة؛ ونمط اللوحة فردي/مجموعات مع أسماء المجموعات.

**النشر:** الواجهة عبر GitHub Pages كالمعتاد. الـAPI صار ينشر تلقائيًا: `.github/workflows/api-deploy.yml` يبني صورة `ghcr.io/anaqweh/inexc-api` عند أي تغيير في `inexc-api/` ويستدعي `RENDER_DEPLOY_HOOK`. يلزم مرة واحدة: ضبط خدمة Render على الصورة الجديدة وإضافة السر.

**الاختبارات:** `inexc-api/test/course-wall.test.js` (تحويل حقيقي للصور والنصوص)، واختبار متصفح شامل أُجري محليًا قبل النشر.
