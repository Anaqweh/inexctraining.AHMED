## ثانيًا: إصلاح حالات الفشل الثماني القديمة في الاختبارات

كلها كانت تقادمًا في ملفات الاختبار أو بيئة التشغيل بعد تطور الكود، لا أخطاء في المنطق:

| الاختبار | السبب | الإصلاح |
|---|---|---|
| قراءة DOCX/ODS/PPTX/XLS (contact-formats) | بيئة محلية بلا `xlrd` | تثبيت تبعيات Dockerfile محليًا (`pip install xlrd Pillow`)؛ لا تغيير بالكود |
| مسار التسجيل الفعلي (course-catalog-payments) | المسار أضيف له وسيط `rejectSuppressedCourse` | تمريره في سياق الاختبار (تمريرة شفافة؛ الحظر له اختباراته) |
| CSV التصدير (message-center) | `trainingPackageText` غير معرفة بالسياق | إضافتها للسياق كما في `server.js` |
| روابط الإلغاء القديمة (message-suppression) | المقطع المقتطع صار يحوي `app.post` | تعريف `post` فارغ بالسياق |
| شاشة الباقات للمسؤول (membership-payment-ui) | الشاشة تعمدت إخفاء طلبات سترايب المعلقة (تُتابع من دليل المشترين، والتأكيد عبر Webhook) | تحديث التوقعات لتوثيق هذا العقد: الصادر بلا زر اعتماد، والمعلق الإلكتروني لا يُعرض هنا |
| مشاركة PNG للبطاقة (membership-card-design) | المعاينة صارت صورة PNG الفعلية عبر `URL.createObjectURL` غير المتوفرة في jsdom | polyfill في الاختبار + توكيدات على الصورة بدل DOM البطاقة |
| تطابق الإخراج القديم (message-blue) | `renderMail` وُحّدت بكتلة إلغاء اشتراك جديدة دون إعادة تجميد النسخة المرجعية | إعادة تجميد تذييل `message-mail-legacy.js` (جدول الإلغاء ونص «Unsubscribe from these emails») — التغيير المتعمد الوحيد على ملف غير اختباري |

النتيجة: حزمة الاختبارات الكاملة خضراء 100% — أي كسر مستقبلي سيظهر فورًا بدل الضياع وسط «إخفاقات معروفة».
