# مركز الرسائل: إنشاء الرسالة في خطوات — 2026-11-05

إعادة ترتيب واجهة «إنشاء وإرسال» فقط في `message-studio-ui.js` و`message-studio.css`. لا تغيير على أي منطق إرسال أو حفظ أو API؛ جميع الحقول بمعرفاتها ومعالجاتها كما هي، وجرى نقل الكتل وإعادة تغليفها فقط.

## المشكلة
كانت صفحة الإنشاء عمودًا واحدًا طويلًا يبدأ بمحرر التصميم مفتوحًا (ثماني مناطق) قبل الوصول إلى المحتوى والمستلمين، مع أربعة صفوف تنقّل متراكمة (قشرة الإدارة + ترويسة الاستوديو + تبويباته + خريطة التصميم).

## الترتيب الجديد
1. **اكتب رسالتك**: العنوان، التمهيدي، والمحرر — أول ما يراه المستخدم.
2. **اختر المستلمين**: كانت داخل طيّة أسفل الصفحة؛ أصبحت بطاقة دائمة الظهور.
3. **المرفق وموعد الإرسال**: بطاقة مستقلة مفتوحة.
4. **المظهر والتصميم (اختياري)**: محرر التصميم كاملًا انتقل إلى الأسفل **مطويًا افتراضيًا** وبداخله خريطة «تعديل أجزاء القالب»؛ زر `data-edit-region` ما زال يفتحه ويقفز للمنطقة.

تحسينات مرافقة: إخفاء ترويسة الاستوديو الكبيرة داخل قشرة الإدارة (العنوان موجود في شريط القشرة) مع إبقاء زرَّي الإجراء؛ إخفاء تبويب «المشتركون الجدد» المكرر من تنقّل الاستوديو داخل القشرة فقط (يبقى في التبويبات الفرعية للمركز)؛ إبراز «مراجعة الإرسال» في الشريط السفلي الثابت.

## التحقق
`node --check` للملفين، واختبارات الاستوديو message-workspace-ui وmessage-primary-button-ui وmessage-memberships وmessage-studio5 وmessage-subscriber-notice-ui وmessage-subscription-ui: 25/25 ناجحة (يبقى إخفاق message-blue القديم السابق لأي تعديل). معاينة بصرية فعلية سطح مكتب وهاتف بمحاكاة API كاملة، بدون أخطاء Console. أرقام الإصدارات: `?v=20261105-flow1`.
