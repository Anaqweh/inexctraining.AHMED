# تنظيم لوحة الإدارة: مراكز موحّدة — 2026-11-05

تحسين ترتيب لوحة الإدارة فقط (`admin-shell.js` و`admin-shell.css`). لا تغيير على الفواتير، أو Stripe وطرق الدفع، أو أي بيانات أو أسماء محفوظة، ولا على أي مسار API أو ملف وحدة. جميع الأقسام والأزرار والنماذج والمعالجات الأصلية بقيت كما هي؛ القشرة تعيد ترتيب العناصر الموجودة وتتنقل بوكالة النقر على أزرارها الأصلية، دون نسخ أو استبدال.

## الفكرة: دمج الصفحات المتناثرة في مراكز

كانت القائمة الجانبية تعرض 15 قسمًا. أصبحت 7 عناصر على نمط لوحات الإدارة العالمية (Shopify/Stripe):

| عنصر القائمة | يضم |
|---|---|
| نظرة عامة | المؤشرات + دليل كل الأقسام |
| طلبات التسجيل | (مستقل) |
| **الدورات التدريبية** (مركز) | الدورات · المشروعات · بطاقات الدورات · طالبو الشهادات |
| الخدمات | (مستقل) |
| **الباقات والمتدربون** (مركز) | الباقات التدريبية · المشترون والبطاقات |
| **التواصل** (مركز) | مركز الرسائل · المشتركون الجدد · تنبيهات الدورات · آراء المتدربين |
| **الإعدادات** (مركز) | طرق الدفع · هوية الموقع |

داخل كل مركز يظهر شريط تبويبات فرعية أعلى المحتوى (ثابت عند التمرير)، وكل تبويب ينقر زر القسم الأصلي نفسه، فتبقى سلوكيات التحميل الكسول، واستعادة المسودات، وروابط `#hash`، وجميع الاختبارات القديمة سليمة. أي قسم جديد لا ينتمي لمركز يظهر عنصرًا مستقلًا تلقائيًا.

## تفاصيل التنفيذ

- أزرار الأقسام المدموجة تبقى في `.tabs` (مخفية) لأن `admin-workspace.js` يعيد التنقل عبرها؛ البحث في القائمة يُظهرها مباشرة عند التطابق.
- زر المركز يفتح آخر قسم استُخدم فيه (محفوظ في `sessionStorage: inexc_admin_hub_last_v1`) وإلا أول قسم مركّب.
- تمييز المركز النشط عبر `aria-current="page"` فقط — وليس class‏ `active` — حتى يبقى أول `.tabs button.active` هو زر القسم الحقيقي كما تفترض اختبارات الاستعادة.
- شارة عدّاد حية في التبويب الفرعي «المشتركون الجدد» تعكس `[data-new-subscriber-count]`.
- مسار الترويسة يعرض «INEXC · اسم المركز»، ودليل «جميع الأقسام» في النظرة العامة يتجمّع حسب المراكز.
- احتفظنا بما سبق: شريط علوي ثابت، اختصار `/` للبحث، عدّاد الجلسة، درج الهاتف.
- درس أثناء التنفيذ: `classList.remove()` غير المشروط داخل منطقة يراقبها `MutationObserver(attributeFilter:['class'])` يكتب الخاصية حتى بلا تغيير ويسبب حلقة لا نهائية — كل تعديل class/attribute في `sync()` مشروط بالاختلاف.

## التحقق

- `admin-shell.test.js` أعيدت كتابة اختباري التنظيم: المراكز والتبويبات الفرعية بالوكالة، والبحث يكشف المدموج، والشارة الحية، وتذكّر آخر قسم. مجموع قشرة/جلسة/تنقل/دخل/خدمات/واجهات الإدارة: 57/57 ناجحة، ومنها اختبار التكامل الكامل `navigation-performance` الذي يحمّل `admin-portal.html` الحقيقي بكل سكربتاته ويستعيد كل قسم بعد التحديث.
- حزمة الاختبارات الكاملة: نفس نتيجة النسخة الأصلية قبل أي تعديل — 8 حالات فشل موجودة مسبقًا في ملف الرفع (عدم تطابق قديم حول `trainingPackageText` بين `server.js` واختباراته) بلا زيادة أو نقصان.
- معاينة بصرية فعلية: سطح مكتب 1500px (نظرة عامة، مركز الدورات، تبديل تبويب طالبو الشهادات، مركز التواصل، إعادة تحميل تستعيد آخر قسم) وهاتف 390px (الدرج والمحتوى)، بدون أي أخطاء Console.
